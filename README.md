# Daily Planner

تطبيق تخطيط يومي شخصي: مهام يومية وأسبوعية، عادات وصلوات، إحصاء، أنظمة تنظيم الوقت.
النسخة الأولى تحفظ البيانات على الجهاز فقط. القرآن والألعاب والمزامنة (Firebase) "قريبًا".

## تشغيل محلي
    npm install
    npm run dev

## بناء ملف APK للأندرويد (بدون جوجل بلاي)
1. أنشئ مستودع GitHub خاص وارفع هذا المجلد كاملًا.
2. من تبويب Actions شغّل "Build Android APK".
3. بعد انتهائه حمّل الملف `daily-planner-apk` من أسفل صفحة التشغيل، وثبّت `app-debug.apk` على التليفون
   (فعّل "التثبيت من مصادر غير معروفة").

> ملاحظة: ملف بناء الـAPK لم يُختبر بعد. إن فشل، أرسل رسالة الخطأ من Actions وسأصلحه.
